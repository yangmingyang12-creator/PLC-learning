# PLC-learning

杨铭洋（喵喵）| 电气自动化技术 | 目标：电气调试工程师

这里记录我学 PLC 的项目和练习，用的都是西门子 S7-1200 1215C DC/DC/DC，博途 TIA Portal V18。

## 项目 1：三轴吸料放料

- PLC：西门子 S7-1200 1215C DC/DC/DC，博途 V18，HMI 组态
- 三轴：三台伺服电机
- 输入：接近开关（限位、原点检测）、光电传感器（有无料检测）、启动 / 停止 / 急停等按钮
- 输出：伺服电机、电磁阀气缸
- HMI：启动、手动 / 自动切换、初始化切换、急停报警、暂停、状态显示

流程：上电先初始化回原点。自动模式下定位 → 气缸下降吸料 → 上升移动 → 放料 → 回原点循环。急停和缺料有报警联锁。

## 项目 2：电机正反转

梯形图练习，带自锁和互锁。

| 点位 | 信号 | 说明 |
| --- | --- | --- |
| I0.0 | 停止 SB3 | 常闭 |
| I0.1 | 正转启动 SB1 | 常开 |
| I0.2 | 反转启动 SB2 | 常开 |
| I0.3 | 热继电器 FR | 常闭 |
| I0.4 | 急停 | 常闭 |
| Q0.0 | 正转接触器 KM1 | 输出 |
| Q0.1 | 反转接触器 KM2 | 输出 |

逻辑：正转启动后 Q0.0 自锁，同时用 Q0.1 的常闭触点互锁；反转同理。停止、热继电器、急停断开时，两个方向都停。

注意：1215C DC/DC/DC 是晶体管输出 24V，不能直接带交流接触器线圈，Q 点要先带中间继电器，再带 KM1 / KM2，硬件上也要用辅助常闭触点做互锁。
